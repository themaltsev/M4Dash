# M4 PC Monitor Portable — Windows x64

1. Распакуйте EXE и ICO в writable-папку.
2. Запустите `M4PCMonitor.exe`.
3. Первый запуск создаёт `settings.json` рядом с EXE. При обновлении заменяйте только EXE.
4. Ярлык рабочего стола можно создать вручную или держать рядом со своей portable-папкой.

Настройки автозапуска выключены по умолчанию. Данные оборудования и локального LM Studio отображаются в окне; индикатор загрузки CPU отображается на кнопке приложения в панели задач Windows.
