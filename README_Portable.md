# M4 PC Monitor Portable — Windows x64

1. Распакуйте все файлы архива в доступную для записи папку (EXE, ICO, `hardware-sensors.ps1`, `LibreHardwareMonitorLib.dll` и лицензию).
2. Запустите `M4PCMonitor.exe`.
3. Первый запуск создаёт `settings.json` рядом с EXE. При обновлении заменяйте EXE и не удаляйте `settings.json`.
4. В архиве также есть каталог `icons/` с SVG-исходником и Windows/macOS/Linux вариантами. На Windows ярлык можно создать вручную; скрипт проекта `scripts/deploy-portable.ps1` создаёт ярлык автоматически.

Во вкладке «Расположение» верхняя и нижняя строки каждой группы выбираются чекбоксами. Выбранные датчики материнской платы можно включать в группы отдельно и задавать им пользовательские имена. CPU отображается в формате `CPU 3.7 GHz: 10% 35°C`; RAM — `DDR4 3.6 GHz: 14/32 GB`. Живой bandwidth оперативной памяти не выводится: текущий провайдер его не отдаёт, а неподходящий счётчик вместо него не используется.

Настройки автозапуска выключены по умолчанию. Данные CPU и материнской платы берутся из LibreHardwareMonitor; прочие устройства и локальный LM Studio опрашиваются приложением. По умолчанию панель группирует показатели в три двухстрочные колонки: сеть получено/отправлено, CPU/RAM и GPU/LLM. Настройте порядок включённых групп во вкладке «Расположение»; выключенные блоки и устройства в списке скрываются. Отмеченные сетевые интерфейсы суммируются, отдельными колонками они не выводятся. Для сети и каждого диска отдельно выбираются MiB/s или Mb/s во вкладке «Датчики». Во вкладке «Оформление» можно выбрать системный шрифт или кнопкой «Добавить шрифт…» скопировать TTF/OTF в каталог `fonts` рядом с EXE; шрифт не устанавливается в Windows глобально.
