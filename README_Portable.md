# M4Dash Portable — Windows x64

1. Windows: можно использовать Portable ZIP `M4Dash-Portable-v<version>-x64.zip` или установщик `M4Dash-Setup-<version>-x64.exe`.
2. Для Portable распакуйте все файлы архива в доступную для записи папку (EXE, ICO, `hardware-sensors.ps1`, `LibreHardwareMonitorLib.dll` и лицензию).
3. Запустите `M4Dash.exe`.
4. Первый запуск создаёт `settings.json` рядом с EXE. Настройки сохраняются при обновлении как Portable, так и через Setup.
5. В архиве Portable также есть каталог `icons/` с SVG-исходником монитора с графиком пульса и вариантами иконок.

Во вкладке «Датчики» внизу находятся настройки LM Studio: имя блока, API и путь к `lms.exe`. Во вкладке «Расположение» верхняя и нижняя строки каждой группы выбираются чекбоксами. Выбранные датчики материнской платы можно включать в группы отдельно и задавать им пользовательские имена. CPU отображается в формате `CPU 3.7 GHz: 10% 35°C`; RAM — `DDR4 3.6 GHz: 14/32 GB`. Живой bandwidth оперативной памяти не выводится: текущий провайдер его не отдаёт, а неподходящий счётчик вместо него не используется.

При запуске в режиме «В трее» окно изначально скрыто и не появляется на экране; мониторинг панели задач продолжает обновляться в фоне. Настройки автозапуска выключены по умолчанию. Данные CPU и материнской платы берутся из LibreHardwareMonitor; прочие устройства и локальный LM Studio опрашиваются приложением. По умолчанию панель группирует показатели в три двухстрочные колонки: сеть получено/отправлено, CPU/RAM и GPU/LLM. Настройте порядок включённых групп во вкладке «Расположение»; выключенные блоки и устройства в списке скрываются. Отмеченные сетевые интерфейсы суммируются, отдельными колонками они не выводятся. Для сети и каждого диска отдельно выбираются MiB/s или Mb/s во вкладке «Датчики». Во вкладке «Общие» можно выбрать язык (по умолчанию English) и тему: «Как в системе» (по умолчанию), светлая или тёмная. Поддерживаются русский, английский, бразильский португальский, персидский, испанский, французский, итальянский и китайский. В разделе оформления можно выбрать системный шрифт или кнопкой «Добавить шрифт…» скопировать TTF/OTF в каталог `fonts` рядом с EXE; шрифт не устанавливается в Windows глобально. В блоке «Обновления» можно проверить GitHub вручную или дождаться автоматической проверки при старте; скачивание новой версии начинается только после подтверждения.
